# קישור אקולוגי - EchoLink-System 

## תיאור כללי
**קישור אקולוגי (EcoLink)** הוא משחק סימולציה אקולוגית שבו השחקן בונה ומאזן מערכת אקולוגית חיה. השחקן ממקם צמחים, בעלי חיים, מקורות מים ואלמנטי טבע על grid דו-ממדי, והכל מתחיל ל"חיות" - צמחים גדלים, ארנבות אוכלות דשא, זאבים צדים ארנבות. המטרה היא לשמור על שרשרת המזון מאוזנת למשך זמן מוגדר, תוך התמודדות עם אירועי טבע (בצורות, גשם) ומשאבים מוגבלים.  
ז'אנר: Simulation, Strategy, Educational
קהל יעד: גילאי 10+, חובבי סימולציה, משחקי בנייה, ומי שמתעניין באקולוגיה
